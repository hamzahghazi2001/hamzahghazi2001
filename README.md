## Featured work

### 🔐 [hybridAUTH — Hybrid Authentication for E-Commerce](https://github.com/hamzahghazi2001/hybridAUTH-demo)

My BSc honours dissertation implementation: a **passkey-first authentication prototype** for e-commerce using WebAuthn, hardened account recovery and step-up re-authentication.

- Passkey registration and authentication with **FIDO2/WebAuthn**
- Magic-link and single-use backup-code recovery
- Forced passkey re-enrolment after recovery
- Step-up re-authentication for sensitive actions
- **10 pytest security tests** mapped against STRIDE threats
