## Featured work

### 🔐 [hybridAUTH: Hybrid Authentication for E-Commerce](https://github.com/hamzahghazi2001/hybridAUTH-demo)

My dissertation project — passkey-first authentication, hardened account recovery, and step-up reauthentication for sensitive actions.

- Passkey registration and authentication with **FIDO2/WebAuthn**
- Email magic-link and single-use backup-code recovery
- Forces passkey re-enrolment after account recovery
- Recent-authentication checks before sensitive actions
- **10 pytest security tests** mapped against STRIDE threats
