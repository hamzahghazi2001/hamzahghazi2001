## Featured engineering work

### 🔐 [hybridAUTH](https://github.com/hamzahghazi2001/hybridAUTH-demo)

Passkey-first authentication prototype built around **WebAuthn, hardened recovery, recent reauthentication, and security testing**.

**Technical highlights**
- WebAuthn registration and authentication ceremonies
- Email recovery with hashed, expiring, single-use tokens
- Offline backup-code recovery with one-time consumption
- Forced passkey re-enrolment after recovery
- Recent-authentication gates for sensitive actions
- Account lockout and audit logging
- 10 scripted `pytest` security tests mapped to STRIDE threats
