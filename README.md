## `02 // FEATURED_BUILDS`

### 🔐 [hybridAUTH](https://github.com/hamzahghazi2001/hybridAUTH-demo)

Passkey-first authentication prototype focused on **authentication state, hardened recovery, step-up reauthentication, and security failure paths**.

- Separate WebAuthn registration and authentication ceremonies
- Hashed, expiring, single-use email recovery tokens
- One-time offline backup-code recovery
- Forced passkey re-enrolment after account recovery
- Recent-authentication gates for sensitive actions
- Account lockout and security event logging
- **10 scripted pytest security tests** covering replay, expiry, lockout, stale sessions, restricted recovery state, and identity mismatch
- Threat modelling against **STRIDE**
