## Featured work

### 🔐 [hybridAUTH: Hybrid Authentication for E-Commerce](https://github.com/hamzahghazi2001/hybridAUTH-demo)

My BSc honours dissertation implementation, focused on passkey first authentication, hardened account recovery and step up reauthentication.

* Implemented passkey registration and authentication with **FIDO2/WebAuthn**
* Added email magic link and single use backup code recovery
* Forced passkey reenrolment after recovery
* Added recent authentication checks for sensitive actions
* Evaluated the design with **10 pytest security tests** mapped against STRIDE threats
